Sobre mí

Developer &
Server Creator

Soy Harlex FX, desarrollador especializado en crear servidores de Minecraft desde cero. Con más de 6 años de experiencia, domino desde la configuración básica de plugins hasta redes complejas con múltiples servidores interconectados.

Mi pasión por los videojuegos y la programación se fusiona para crear experiencias únicas. También desarrollo sitios web modernos y soluciones personalizadas para proyectos gaming.

Trabajo con Paper, Spigot, BungeeCord, Velocity, y un ecosistema completo de plugins. Cada proyecto es único, cada servidor es una obra.

PaperMC BungeeCord Velocity Spigot Java YAML MySQL Linux Docker JavaScript React Node.js
